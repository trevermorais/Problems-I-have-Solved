# Problems I have Solved

## Image Modifier

Wrote an image-filtering program in C that applies grayscale, sepia, reflection, and blur effects to BMP images by manipulating raw pixel data directly. Also i added a project where in the code recovers the missing data from the image.

## Audio Modifier

Wrote an audio-enhancing program in C that increases the magnitude of the sound wave in the .wav file and reads it back into a .wav output file.

## Caesar Encryption

Caesar encryption is a basic substitution method that shifts each letter in a message by a fixed number of positions down the alphabet. Im immulating the same principle using a C program

## DNA Sequencing

Built a DNA-matching program that identifies an individual from a CSV database of Short Tandem Repeat (STR) counts, comparing sequences using string parsing and dictionary lookups.

## Logic Problems - Plurality

A vote-tallying program that implements a plurality election — takes a list of votes and prints the candidate(s) with the most votes, handling ties.

## Scrabble Game

A program that computes and compares Scrabble scores for two input words based on official letter point values, then declares the winner.

## Data Structure Projects

A spell-checker that loads a 140,000+ word dictionary into a custom-built hash table, then checks a text file for misspellings — implementation focused on hashing and Big O efficiency.
